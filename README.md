# BrickPix Website

This repository contains the static website for BrickPix — a small web project that showcases the
BrickPix app and example Lego-mosaic projects. The site is implemented with plain HTML and CSS and is intended to be lightweight and easy to host.

This README provides a quick overview, how to preview the site locally, the repository structure,
and a few notes on contributing.

## Features

- Simple, responsive static site built with HTML and CSS
- Pages included: Home, Example Projects, About
- Top-right site navigation added (pure HTML/CSS;)

## Quick start — preview locally

You can preview the site by opening the HTML files directly in your browser (double-click the
`index.html` file).

## Project structure

Key files and folders:

- `index.html` — Home page
- `about.html` — About page
- `example-projects.html` — Gallery of example projects
- `css/styles.css` — Main stylesheet
- `images/` — Project images and icons
